# FluBioStack 交付说明 · 2026-09-19

## 访问方式

```bat
cd flubiostack\web
start.bat
```

默认端口已同步为 **3434**（与当前 dev server 一致），启动器行为：

- `start.bat` → 使用固定端口 `3434`
- `start.bat --port 3000` → 指定其它端口
- `start.bat --port-auto` → 自动在 `3434-3533` 范围内挑选空闲端口
- `start.bat --dev` → 开发模式（热更新）
- `start.bat --build` → 强制先执行 `npm run build`

访问地址：http://localhost:3434/

## 本次优化内容

### 1. 顶栏 / 侧栏搜索去重
删除左侧栏中与顶部导航栏功能重复的搜索框，仅保留顶栏 `Ctrl+K` 命令面板入口。

文件：`src/components/layout/AppShell.tsx`

### 2. 时间显示改为北京时间
原实现使用 `getUTCHours()` 等方法但标注为 UTC，与北京时间不符。现改为：

```ts
new Intl.DateTimeFormat('en-GB', { timeZone: 'Asia/Shanghai', hour12: false, ... })
```

顶栏时钟现在准确显示北京时间（CST，UTC+8）。

文件：`src/components/layout/AppShell.tsx`

### 3. 中央舞台重新设计
- **CORE 节点**：从写死的模板坐标（430/194，对应 1000×500 老模板）改为真正基于容器尺寸动态居中（`cx = w/2, cy = h/2`）
- **5 个卫星节点**：改用黄金角分布算法（`angle = i × 137.5° - 90°`），半径按舞台短边自适应（`min(w,h) × 0.30`），不再溢出或被裁切
- **光线连接**：`StageLines.tsx` 从硬编码模板像素改为基于 SVG 动态绘制「中心→卫星」的连线，采用 `stroke-dashoffset` 动画模拟能量流动，颜色与对应卫星主题色渐变匹配
- **节点信息对齐**：核对 5 个卫星节点文案与真实分析模块 (`/analysis` 页面的 `scfv / multiomics / circuit / epidemic` 模块 + `/database` 的 IP 风控) 完全一致，避免误导性描述
- **Hover 详情卡**：新增 `SatelliteDetailCard.tsx`，鼠标悬停卫星节点时展示该模块的真实关键指标（如 scFv 的 ΔG 亲和力范围、SEIR 的 R0 值等）
- **舞台高度**：从 `480/560/640px` 调整为 `460/520/560px`，避免大屏下节点过度分散、背景显得过大

文件：
- `src/components/home/HeroScene3D.tsx`
- `src/components/home/StageLines.tsx`
- `src/components/home/SatelliteNode.tsx`
- `src/components/home/SatelliteDetailCard.tsx`（新增）
- `src/app/page.tsx`
- `src/styles/globals.css`

### 4. Logo 重新设计
原 Logo 是简单的圆角方块 + DNA 图标堆叠，视觉单薄。现改为独立组件 `BrandLogo.tsx`：

- 六边形（Hexagon）外框，象征"结构化 / 数据库"
- 内部双螺旋 DNA 线条动画，交替呼吸发光
- 中心核心点带柔和外发光效果（`brand-logo__glow`），呼应中央舞台 CORE 的设计语言
- 渐变描边（青 → 紫 → 绿），与整站配色系统一致

文件：`src/components/layout/BrandLogo.tsx`（新增）+ `src/styles/globals.css`
