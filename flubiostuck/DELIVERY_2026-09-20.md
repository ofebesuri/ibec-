## 一、启动方式

```bat
cd E:\pttz\flubiostack\web
start.bat                    :: 生产模式，自动检测 build 产物，端口 3434
start.bat --dev              :: 开发模式（热更新）
start.bat --port 3000        :: 指定端口
start.bat --port-auto        :: 在 3434-3533 范围内挑空闲端口
start.bat --build            :: 强制先跑 npm run build
start.bat --print-check      :: CI 模式：只打印 6 端点 HTTP 状态
start.bat --no-browser       :: 不自动打开浏览器
start.bat --flush-cache      :: 清空 .next/cache

stop.bat                     :: 关闭当前端口的服务器
stop.bat --all               :: 终止所有 Node.js 进程
```

顶层（仓库根）快捷入口：`E:\pttz\start.bat` / `E:\pttz\stop.bat`，自动定位 web 子目录后转发所有参数。
